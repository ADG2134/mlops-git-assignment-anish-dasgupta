# mlops-git-assignment-anish-dasgupta

## Project Description
This repository demonstrates Git and version control workflows as part of the MLOps course. It covers branching strategies, pull requests, merge conflict resolution, and branch protection rules.

## Prerequisites
- Git 2.30+
- Python 3.9+
- GitHub account

## Setup Instructions
git clone https://github.com/ADG2134/mlops-git-assignment-anish-dasgupta.git
cd mlops-git-assignment-anish-dasgupta
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

## Branch Strategy
| Branch | Purpose |
|---|---|
| main | Production-ready, protected |
| develop | Integration branch, default for PRs |
| feature/* | Individual feature work |
